# Rule interpretations

- Each Dragon square uses its pictured Dragon card: Spiral 35, Serpent 17, Winged 26, Golden Beast 20. Encounter order does not change this mapping.
- Landing on a printed Hero card grants a copy, including on later visits. Thor is consumed when used to steal. Loki is consumed when used. Frexia remains in inventory but can be activated only once per player per game.
- The original Loki text says “snake”; Dragons are the board's hazards, so Loki shares the Dragon penalty.
- Fate rerolls both dice before selection or ignores one Dragon for 1 Fate. Ladders activate automatically on landing; passing a ladder does not activate it.
- Per the requested finish rule, a traveler must land exactly on square 100. An overshooting die causes no movement and ends the turn.
